## T1.16: Supervise bounded fixture worker processes

### Objective
Supervisor launches only the owned fake-agent fixture, records process/run identity, heartbeat, timeout and result; pause kills process group after TERM/KILL grace and fences IPC; cleans only owned task workspaces. Actual OCI/Codex sandbox is deferred to E2.

### Scope
- `internal/supervisor/supervisor.go`
- `tests/integration/supervisor_test.go`
- `tests/testutil/fakeagent/main.go`

### Out of scope
Other task-owned modules, live GitHub mutations, paid model calls, production deployment, and changes to the RFC's guarantees. Coordinate contract amendments through the coordinator instead of expanding file ownership.

### Dependencies
T1.8, T1.10, T1.11; see `docs/plan.md`. Interfaces are frozen by T1.3. Imported dependencies can be consumed but their files are not owned by this task.

### Acceptance criteria
- Production paths contain no default test doubles or hardcoded success.
- Fixture execution is available only through test injection; production configuration cannot select it. Test production startup rejects a missing OCI adapter instead of running a fake worker.
- Supervisor launches only the owned fake-agent fixture, records process/run identity, heartbeat, timeout and result; pause kills process group after TERM/KILL grace and fences IPC; cleans only owned task workspaces. Actual OCI/Codex sandbox is deferred to E2.
- For behavior changes, perform a genuine-red check: Make the fixture ignore TERM and verify KILL plus stale-result denial after the configured grace. Restore the behavior and record failing and passing verification outputs. Any intentional breakage belongs only in the task's owned isolated worktree.
- Tests must exercise the real boundary stated above; database/Redis integration fixtures fail if required services are missing, rather than skip.
- Keep new API status/body shapes consistent with `docs/contracts.md` and tested through real HTTP requests when applicable.
