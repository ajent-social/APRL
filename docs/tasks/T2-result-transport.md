# T2.2/T2.3 result transport contracts

Use Go standard library, existing clock/results/contracts interfaces. Trusted host constructs credentials; keys and tokens never enter ProcessSpec, worker environment or untrusted payloads. The durable results service remains authoritative for immutable admission/generation/lease/replay. Authenticated transport does not invent lifecycle, billing or cancellation evidence. CLI remains fail-closed.

T2.2 owns internal/hostauth only: constructor pins issuer/audience, key IDs/key rotation, max TTL (at most 15 minutes), current clock; cloned keys at least 32 bytes. Fixed version HMAC-SHA256 framing, strict bounded encoding and claims, iat/nbf/exp with no stale/future acceptance, canonical UUID task/run and bounded identity/credential. Auth requires HTTPS POST /internal/results, exactly one well-formed Authorization bearer value, and returns only signed principal. Expose host token issuance plus Token(ctx, results.Principal) for resultclient integration; never parse request body for identity. Negative key/token/time/audience/issuer/transport tests.

T2.3 owns internal/resultclient only: constructor pins exact HTTPS /internal/results endpoint, bounded timeout/body sizes, trusted TLS client without redirects; TokenSource.Token(context.Context, results.Principal) supplies per-submission host token. Submit validates principal matches result task/run, contracts.Result validity, posts JSON once with bearer token, requires HTTP 200 strict accepted=true matching operation_id. Bounded, safe typed errors for unauthorized/forbidden/stale/protocol/unavailable/unknown network outcomes; no raw body/token/URL in errors, no auto retries. Real TLS test server checks method/path/status/body, redirect and mismatched or malformed acceptance, timeout/5xx/oversize. Use trusted TLS roots for test server, never insecure skip verification.

Coordinator owns real PostgreSQL/TLS integration in tests/api plus plan/evidence; shared changes require coordinator agreement. Workers edit/format only; coordinator uses hosted CI while local load is held. No new third-party dependencies.
