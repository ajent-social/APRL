## T1.6: Accept signed webhook deliveries durably

### Objective
POST /webhooks/github returns 202 with delivery_id/accepted on a committed signed body, 200 with duplicate true on replay, 401 with error invalid_signature on bad HMAC, and 503 with error storage_unavailable when commit fails; exact-byte HMAC precedes parsing/sanitization.

### Scope
- `internal/httpapi/webhooks.go`
- `tests/api/webhooks_test.go`

### Out of scope
Other task-owned modules, live GitHub mutations, paid model calls, production deployment, and changes to the RFC's guarantees. Coordinate contract amendments through the coordinator instead of expanding file ownership.

### Dependencies
T1.5; see `docs/plan.md`. Interfaces are frozen by T1.3. Imported dependencies can be consumed but their files are not owned by this task.

- Keep new API status/body shapes consistent with `docs/contracts.md` and tested through real HTTP requests when applicable.
